## 5. Image SEO

In the architectural cladding business, visual search is a massive weapon.

- **Filenames:** `white-fluted-wpc-wall-panel-bedroom-gurgaon.webp` (NOT `IMG_8237.jpg`)
- Descriptive `alt` tags
- Explicit dimensions (width/height attributes)
- Next-Gen Formats: WebP / AVIF
- Proper compression
- Responsive sizes (`srcset`)
- Image sitemap
- Product schema where appropriate
